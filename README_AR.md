# Earth 3D Live Wallpaper — نسخة التطبيق المباشر

هذه النسخة تعمل بطريقتين:

1. **تطبيق أندرويد مباشر**: عند فتح التطبيق تظهر الأرض المتحركة فوراً بكامل الشاشة، مع استجابة لميلان الهاتف والسحب واللمس.
2. **Live Wallpaper**: زر «تعيين كخلفية متحركة» يفتح شاشة أندرويد لتثبيت نفس المشهد كخلفية حية.

## المزايا
- دوران تلقائي للأرض.
- انتقال ناعم بين لقطات دوران الأرض الخمس.
- Parallax مع ميلان الهاتف باستخدام Rotation Vector، مع Gyroscope كخيار احتياطي.
- تدوير إضافي بالسحب يميناً ويساراً.
- جزيئات ضوئية عند اللمس والسحب.
- يعمل من Android 8.0 (API 26) وما بعده.

## البناء
المشروع جاهز للبناء في Android Studio باستخدام Gradle. افتح مجلد المشروع ثم نفّذ Build > Build APK(s).
